# Exercise 3 (self-paced) — instructor notes

> Companion to [`exercise-3-self-paced-assignment.md`](exercise-3-self-paced-assignment.md) /
> `.pdf`. That document goes to students as-is — keep these notes out of it. This file is for you
> and anyone co-teaching the session.

Three moments in the student handout are worth watching or steering. Each note below names the
section of the student document it attaches to.

## 1. Framing talk — "Why this exercise exists"

If you're running this with a group, use this section as a five-minute framing talk **before**
anyone opens an editor. Put the "Exercise 2 vs. Exercise 3" comparison table on a shared screen and
ask:

> Which row would you have skipped if nothing made you write it down?

Only after they answer, reveal that `plan.md` exists for exactly that reason. Landing this before
the mechanics start makes the rest of the document read as motivated rather than bureaucratic.

## 2. Checkpoint — "The shared Method block"

Ask the learner, out loud, which part of the Method block is "the skill" and which part is just
formatting. The honest answer is: **all of it** — the file-versus-paste distinction is packaging,
not substance. A tool with a skills feature loads that same text from a file; here, the student is
the loader.

If they can't articulate that distinction, the core idea hasn't landed yet. Better to catch it here
than at the debrief, while there's still a whole exercise left to make it concrete.

## 3. Grading gate — "Completion contract"

A green test run earns partial credit at best. Before accepting the exercise as done, ask to see:

- the `plan.md` **Human checkpoint** block (`Decision: approved`, name, date, in the learner's own
  words); and
- the **reviewer's findings**, reported from an independent conversation, before any fix.

If a learner can't produce both, they most likely collapsed the three roles into one uninterrupted
pass — planner, implementer and reviewer all in the same conversation. That's the single most
common shortcut to watch for, and it quietly defeats the whole point of the exercise: a green build
without those two artefacts is indistinguishable from Exercise 2 with extra steps.
